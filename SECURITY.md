# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.10.x  | Yes       |
| < 0.10  | No        |

## Reporting

To report a security issue, please use [GitHub Security Advisories](https://github.com/sambhal-labs/jaxcross/security/advisories) rather than opening a public issue.

We will acknowledge receipt within 48 hours and provide an initial assessment within 7 days.

## Scope

This policy covers the `crosscat` Python package. Issues in upstream dependencies (JAX, JAXlib, NumPy) should be reported to those projects directly.
